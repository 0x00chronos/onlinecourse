# 超星 MOOC 油猴脚本

文件：`chaoxing-questionbank.user.js`。独立脚本，无 jQuery、远程 `@require`、公共题库或 AI 服务依赖。适配私有化超星常见章节测验、旧版作业、新版 `.questionLi` 作业布局，目前只处理单选/多选。

## 安装和首次配置

1. 安装并启用当前版 Tampermonkey；浏览器如要求用户脚本/开发者模式权限，按扩展提示开启。
2. 启动本项目 Go 服务，打开 [脚本安装地址](http://127.0.0.1:8080/userscripts/chaoxing-questionbank.user.js)。查询页面也提供安装入口。若扩展没有接管，复制此文件到油猴“添加新脚本”并保存。
3. 脚本默认匹配超星域名，以及任意域名下的 `/mycourse/`、`/mooc-ans/`、`/mooc2/`、`/work/`、`/exam-ans/`、`/exam/` 路径。私有平台路径不同，请在脚本头添加实际域名，例如 `// @match https://mooc.your-school.edu/*`。域名只写自己的实际平台。
4. 打开已登录的课程作业/章节测验页，右下角出现“题库助手”。没有出现时可先尝试刷新页面，并检查脚本匹配和扩展启用状态。
5. 展开“连接、课程与适配设置”：填写后端地址（默认 `http://127.0.0.1:8080`，不含 `/api/v1`）、`config.yaml` 中 `server.api_key` 对应的 Token。后端在其他主机时，在脚本头额外增加 `// @connect 后端域名或IP`，不带协议和端口。
6. 确认平台标识、课程名、平台课程 ID、贡献用户名。课程/用户名会尝试从页面和同源父框架识别；缺失时手动补全，再保存。用户名不是经过平台认证的身份凭据。

默认平台标识为 `超星MOOC@<当前主页面Origin>`，区分不同私有化实例。**采集和填写时平台标识、平台课程 ID 必须相同**。如果题目在跨域 iframe 中，两个面板可能默认使用不同平台标识，需要手动统一。不要把作业标题当成课程名称。

课程元数据可按自动识别到的课程 ID 保存覆盖值。没有自动 ID 的页面允许手工填写，但该课程覆盖值不跨页面持久保存，避免把不同课程错误合并。贡献用户名和连接设置可以保存。

## 明天验证的建议顺序

1. 先进入**已经展示正确答案的作业详情/批阅页**，点击“扫描 / 预览”。核对题干是否干净、选项是否完整、课程和用户名是否正确。预览会分别显示“页面可见正确答案”或“未发现明确可见的正确答案”。
2. 点击“上传采集”，确认成功；重复上传一次应显示新增题目为 0。打开后端查询页面，确认题目、答案与贡献者已保存。
3. 进入同一课程中可以编辑答案的题目页面，先点“查询答案”。核对命中结果和鸣谢信息，再点“查询并填写”。即使 A/B 选项顺序不同，也应按内容匹配到当前编号。
4. 核对单选、多选都正确选中。默认遇到已有选择时保留原答案；要测试改写，手动勾选“允许改写已有选择”。完全一致的选择不会反复点击。
5. 脚本只填写当前已加载题目，不点击交卷、提交、保存按钮或下一页。平台自身绑定在选项点击上的暂存/保存行为仍可能运行；最终请按平台流程自行检查和提交。

“停止”会取消正在等待的后端请求并停止后续题目；若某道题已经开始点击，会先完成该题的状态校验。已经完成的上传/填写不会撤销。面板可收起；油猴菜单可显示/隐藏面板。

## 答案采集和填写规则

- 采集页面明确展示的 `正确答案` / `参考答案`，或现代超星 `.correctAnswer .answerCon` 区域。隐藏答案、当前选中项、“我的答案”不会作为正确答案上传。
- 支持 `A`、`AC`、`A、C` 等选项字母；明确与选项文本一致的单个答案或按行分隔的多项文本也可解析。不能唯一映射的答案保持未知，题目仍可上传。
- 同一页面的答案标记如果互相冲突，跳过该题并提示检查选择器。
- 后端精确命中、只有一组候选答案且答案文本能映射到当前选项时才填写。题库冲突、未命中、无答案、页面题目变化、不可编辑或无法确认控件状态时跳过。
- 通过超星可见选项的点击路径触发选择，并核对最终单选/多选状态；未通过校验不会声称填写成功。鸣谢显示在面板对应题目下。
- 纯文本题干/选项中的空白和题型前缀会清理；大小写和标点保留。题干/选项有图片、公式节点或 `font-cxsecret` 时，本版本保守跳过，避免将不完整或乱码文本当作题目。
- 只扫描当前页面及已加载的同源 iframe，最多 5 层。跨域 iframe 由该 frame 内匹配到的脚本单独运行；不会绕过浏览器同源限制。换页、异步加载后重新扫描即可。

## 私有化布局适配

设置中的“高级：私有平台选择器 JSON”可覆盖默认选择器，例如：

```json
{
  "roots": [".questionLi", ".TiMu"],
  "stem": [".mark_name", ".Zy_TItle .fontLabel", ".Zy_TItle .clearfix"],
  "options": [".stem_answer .answerBg", "ul.Zy_ulTop > li"],
  "optionText": [".answer_p", "label.after"],
  "correctAnswer": [".correctAnswer .answerCon"],
  "courseName": [".courseName"],
  "username": [".userName"]
}
```

每项可以是字符串或字符串数组；字段名、JSON 和 CSS 语法会校验。`stem`、`options`、`optionText` 按顺序尝试，返回第一组有效节点；`roots` 和 `correctAnswer` 汇总匹配。`optionText` 同时参与点击目标选择，需要指向选项的可点击内容。

自定义 `correctAnswer` 视为由维护者明确指定的正确答案区域，**不要选择“我的答案”或隐藏 input**。修改适配配置后先检查扫描预览，不要直接上传。

无法识别时点击“复制诊断”，保留识别数量、跳过原因、已脱敏页面 URL 和前 3 道题的文本样本，便于定位版本差异。诊断不包含配置 Token 或用户名字段，但包含题目内容，请自行确认分享范围。

## 通信、存储与常见问题

- 所有业务请求使用 `GM_xmlhttpRequest` 和 `Authorization: Bearer <token>`，只发送到配置后端。请求使用 `anonymous: true`，不主动携带平台 Cookie，禁止重定向；Token 不放到页面 localStorage、URL、日志或诊断报告中。连接信息保存在油猴自身存储，卸载/清除脚本数据可移除。
- 来源 URL 只保留课程、班级、作业、章节等 ID 参数，移除 `enc`、`token`、`uid`、`cpi` 等参数及片段。脱敏链接可能仍要求平台登录，部分页面可能需要从课程入口进入。
- 操作前按平台标识和课程 ID 幂等登记课程；批量上传按来源页分组，并按 UTF-8 体积分包（约 1.5 MiB，每批最多 100 题），适配后端默认 2 MiB 请求限制；重复提交由后端去重。查询/填写按题目顺序执行，默认间隔 400 ms。
- `401`：检查 Token 与服务配置是否一致，本次操作会停止。
- `403 / origin_denied`：若浏览器为 GM 请求附带平台 Origin，将实际私有平台 Origin 加入后端 `server.allowed_origins` 并重启。
- 网络失败：检查服务是否运行、后端地址、证书与 `@connect` 主机权限。`127.0.0.1` 指**运行浏览器的这台电脑**。
- 0 题或状态校验失败：查看操作日志和诊断；可能是 iframe、尚未加载、只读页或私有版本 DOM 差异。

## 自动验证

Go 服务及实际脚本运行不依赖 Node。以下 Node 依赖只用于模拟 DOM 测试（当前 jsdom 要求 Node `^22.22.2`、`^24.15.0` 或 `>=26.0.0`）：

```sh
npm ci
npm test
go test ./...
go build -o bin/questionbank ./cmd/server
npm run test:userscript:integration
```

最后一项会自动启动本地临时端口和独立 SQLite，测试“旧布局采集 → 带 Token 上传 → 新布局选项换序查询 → 单选/多选填写”，结束后关闭服务并删除临时数据库。不会写入默认题库。测试页面为构造样例，仍需要实际私有平台验证。
